About

My core identity is security research - finding, validating, and explaining security issues with a focus on deep technical understanding. Available for remote engagements globally, with async-friendly reporting.

My security work is grounded on 10+ years hands-on inside enterprise infrastructure - the same networks, servers, virtualization stacks, cloud tenants, and DevOps pipelines I now assess for weaknesses. That background is a deliberate advantage: I can read a target the way it was actually built, spot the misconfigurations that plain tool scans miss, and produce write-ups that reproduce cleanly on both a lab VM and the client's own environment.

Thesis: Analysis of network attacks against a server-based intrusion detection system, using the generic forensics framework methodology. Backed further by certifications including CEH, CCNA, Network Security Expert (NSE), and VMware (full list in Certifications).
